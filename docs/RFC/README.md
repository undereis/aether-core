# RFCs

RFCs define major architectural direction before implementation. They are
review artifacts, not runtime behavior.

## Active RFC Documents

- [RFC-0001: Memory Domain](RFC-0001-Memory-Domain.md)
- [RFC-0002: Knowledge Domain](RFC-0002-Knowledge-Domain.md)
- [RFC-0003: Context Domain](RFC-0003-Context-Domain.md)
- RFC-0004: Planning Domain (reserved)
- RFC-0005: Reasoning Domain (reserved)
- RFC-0006: Decision Domain (reserved)
- RFC-0007: Learning Domain (reserved)
- RFC-0008: Perception Domain (reserved)
- [RFC-0009: Efficient Intelligence & Energy-Aware Architecture](RFC-0009-Efficient-Intelligence-Energy-Aware-Architecture.md)

RFC-0004 through RFC-0008 remain reserved for the cognitive domain sequence
approved in CDR-0001. RFC-0009 is a transversal architecture RFC and does not
replace or reorder those domains.
