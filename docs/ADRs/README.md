# Architecture Decision Records

ADRs capture decisions that materially shape Aether's architecture.

Rules:

- Use a numbered file for new records: `ADR-000N-short-title.md`.
- Record context, decision, consequences, and status.
- Prefer reversible decisions when uncertainty is high.
- Revisit decisions through new ADRs instead of editing history silently.

The initial Phase 0 ADR keeps its original filename as a historical bootstrap
record.

## Records

- `0001-phase-0-foundation.md`: Phase 0 foundation.
- `ADR-0002-runtime-version-strategy.md`: production runtime version strategy.
- `ADR-0003-core-runtime-rust.md`: Core Runtime in Rust.
- `ADR-0004-aether-kernel.md`: Aether Kernel orchestration layer.
- `ADR-0005-typed-id-strategy.md`: typed identifier strategy.
